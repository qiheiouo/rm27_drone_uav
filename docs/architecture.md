# 架构说明

设计依据：`General_Plan.md`。核心原则——不是把高飞组系统缩小，
而是重新设计一套 STM32 能承担的最小自主闭环。

## 数据流（当前：真实算法链路）

```
动力学真值（推力矢量模型：推力沿真实机体 z 轴，姿态环带宽限制）
   ├─→ IMU：机体系比力(含重力) + 陀螺 + 固定偏置 + 噪声
   ├─→ ToF：机体 -z 测距（光流尺度 + 估计器 z 通道锚定）
   ├─→ 地面特征点 → 下视相机投影 → 光流帧（像素噪声/id 关联）
   └─→ 目标/基座 marker → 相机投影 → 像素观测（视锥剔除）
                │
IMU ─→ INS 估计器（姿态积分 + Mahony 修正 + VO 水平校正 + ToF 高度融合 + 健康机）
                │                    │
光流帧 ─→ Vision Frontend（旋转补偿 → 最小二乘 → 外点剔除 → 积分 = VO）
                │                    │
                │     像素 + 已知尺寸 + 估计姿态 → 相对位置重建（PnP-lite）
                ↓                    ↓
        Impact Detector      Target / Home Tracker
                │                    │
                └──────────┬─────────┘
                           ↓
        Mission FSM ← Safety（时间预算/围栏）
                           ↓
        Trajectory / Terminal / Recovery / Home Guidance
                           ↓
        GuidanceOutput → Pos Controller → 动力学
```

第三层定位：marker 捕获 → `estimator_notify_relocalized` 注入绝对参考 +
`vf_set_pose` 对齐 VO 坐标系（1 s 冷却 + 最小校正门限防抖）；
marker 不可见时螺旋搜索扩张覆盖漂移偏差。

## 关键设计决策

- **INS + 光流 VO + ToF 融合**：IMU 预测（高带宽）；光流提供水平速度/
  位置积分（Vz 可观性弱，不校正 z）；ToF 锚定 z（二阶互补，
  速度增益 > 位置增益，抑制加速度计 z 偏置积分）。
  VO 失效时纯 IMU 推算并按失效时长降级（TRACKING→DEGRADED→LOST），
  恢复后经 RECOVERING→RELOCALIZED 收敛。
- **姿态估计**：Mahony 互补滤波（加速度计倾斜修正 + 陀螺偏置学习），
  比力偏离 1g 超过 1.5 m/s² 时自动闭锁修正（机动/撞击期间不误修正）。
- **VO 偏航不校正 INS**（kp_vo_yaw=0）：光流偏航与 INS 偏航同源
  （同一陀螺积分），校正会形成正反馈（曾导致撞击后 90° 姿态发散）；
  VO 系与估计系的长期对齐由重定位时的 `vf_set_pose` 完成。
- **光流尺度来自 ToF 而非估计高度**：避免 est 高度 → 光流尺度 →
  est 高度的正反馈（曾导致高度正向发散）。
- **撞击检测**：比力模长偏离 1g（正常机动 <7，撞击 >100）+ 陀螺尖峰，
  连续帧确认；**进入 TARGET_TRACK（新一轮接近）时重新布防**，
  撞击锁存在 RECOVERY 流程中保持——估计器丢失恢复后仍能正确进入 IMPACT。
  仿真中撞击可重复注入（0.5 s 不应期），二次接近会再次触发接触。
- **推力矢量动力学**：平移加速度 = 推力沿真实机体 z 轴分解 - 重力 - 阻尼；
  姿态以有限带宽（10 rad/s）跟踪期望比力方向。翻倾期间推力方向错误
  产生真实的高度/位置损失——翻倾恢复能力由此被真实检验。
- **翻倾恢复（RECOVERY）**：倾角 >20° 时导航层只轻推爬升保高度
  （横向指令在翻倾时无意义），改平交给低层姿态环；倾角 ≤17° 后速度阻尼。
  退出条件 = 稳定时间 + 估计器健康 + 倾角 ≤17° 三者同时满足，
  超时进 EMERGENCY_LAND。`--hard-impact` 注入 >90° 翻倾验证该链路。
- **相机检测**：前视相机找目标、下视相机找基座；像素 + 已知尺寸 →
  相对位置；检测距离由最小像素尺寸自然限制；视锥/图像边界决定可见性。
- **轨迹**：航点间 minimum-jerk 五次多项式（闭式系数、固定维度、
  C2 连续、端点停止），按巡航速度时间分配（峰值 ≈1.34×巡航），
  位置+速度前馈跟踪。完整 MINCO 时空联合优化仍为后续候选。
- **停靠判定（双判据）**：视觉对准判据（marker 可见 + 估计高度 ≤ dock_alt
  + 横向 ≤ 0.08 m）与**机械捕获判据**（已着陆 |v|≤0.08 m/s + 低空 +
  最后在捕获半径 0.15 m 内）。后者不依赖估计高度绝对精度——近地面
  marker 出画 + VO z 漂移时视觉判据可能永远不满足，机械捕获
  （基座停靠结构，Plan 允许自行设计）兜底；低高度 marker 短暂丢失时
  垂直盲降（≤0.35 m），不爬升重搜。

## 坐标系与约定

- 导航系：x/y 水平，z 向上；机体系由姿态四元数定义（机体 z 对齐推力方向）。
- 相机系：z 轴朝前（光轴），安装矩阵 `CAM_MOUNT_FORWARD` / `CAM_MOUNT_DOWN`。
- IMU 量测为机体系比力（含重力，悬停时约为 (0,0,+9.81)）。
- 全部模块：C99、`float32`、固定容量数组、静态内存、无 malloc/STL/异常/RTTI。

## 验证

- 单元测试（7 项）：`test_math`（含四元数）、`test_impact_detector`、
  `test_mission_fsm`（正常链路 + 目标丢失/估计器丢失/超时返航）、
  `test_camera`（投影/重建往返、视锥剔除）、`test_ins_estimator`
  （零漂、姿态收敛、VO 校正、ToF 融合、健康机、撞击盲期）、
  `test_vision_frontend`（平移恢复、旋转补偿、特征不足、外点剔除、积分）、
  `test_trajectory`（边界条件、峰值速度、段间连续、clamp）。
- 集成测试：`mission_closed_loop` + 蒙特卡洛 32 组
  （`mc_seed_1..16` 正常 / `mc_lost_11..20` 撞击 LOST /
  `mc_hard_21..25` 剧烈翻倾 / `mc_truth_mode` 理想对照），共 40 项。
- 扩展手动扫掠 55 组（正常 30 + LOST 15 + 翻倾 10）全部通过。
- 典型指标：任务耗时 avg ~19 s / max ~24 s（预算 30 s），
  停靠误差 ≤0.13 m，剧烈撞击后最大估计误差 <2 m（重定位前）。

## 已知简化（后续迭代候选）

- 地面平面假设：ToF 高度与光流尺度都依赖平坦地面（比赛场地成立）。
- 图像处理前端未实现：特征点提取/跟踪、目标 blob 检测（像素接口已就位）。
- 低层飞控（姿态/角速度环）仅有接口与仿真模型，无实机实现。
- 目标检测假设已知目标尺寸；无分类器/检测网络。
- 无电机/电调/电池模型；时间预算以计时器近似。
